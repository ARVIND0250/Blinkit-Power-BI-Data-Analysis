# Blinkit Power BI Data Analysis

Blinkit grocery sales data analysis project using Power BI, Excel and PowerPoint.

## Project Overview

This project analyzes Blinkit grocery sales data to understand sales performance, outlet types, outlet locations, item categories, customer ratings and outlet establishment trends.

## Tools Used

- Power BI – Dashboard and data visualization
- Power Query Editor – Data cleaning and transformation
- Microsoft Excel – Raw dataset
- Microsoft PowerPoint – Project presentation

## Data Cleaning & Transformation

- Standardized Item Fat Content values such as `LF` and `low fat` to `Low Fat`.
- Standardized `reg` to `Regular`.
- Cleaned Item Weight data.
- Prepared the dataset for analysis and visualization.

## Key KPIs

- Total Sales: 1.20M
- Average Sales: 140.99
- Average Rating: 3.92
- Number of Items: 9K
